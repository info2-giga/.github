# 🚀 IMI Code-Wiki

Willkommen im **Code-Wiki** für den Studiengang **Internationale Medieninformatik (IMI)**! 

Dieses Repository dient als zentrale Sammlung von Codebeispielen, Projekten und Vorlagen aus verschiedenen Modulen des Studiums. Es soll Studierenden als Orientierung und Hilfstellung für eigene Abgaben und Übungen dienen.

---

## 📚 Themenbereiche

Hier findest du Quellcode und Beispiele zu verschiedenen Fachbereichen:

* 🖼️ **Bildverarbeitung (BV):** Algorithmen zur Bildbearbeitung, Filter, Segmentierung und Merkmalsextraktion.
* 🎨 **Computergrafik (CG):** Shader-Programmierung, 2D/3D-Rendering, Transformationen und OpenGL/WebGL-Grundlagen.
* 💻 **Informatik (GDI / ALDA):** Grundlagen der Programmierung, Datenstrukturen, Algorithmen und Entwurfsmuster.
* ☀️ **Raytracing:** Physikalisches Rendering, Strahl-Objekt-Schnittpunkte, Beleuchtungsmodelle und Reflexionen.

---

## 🤝 Mitmachen & Beitragen

Dieses Wiki lebt vom Mitmachen! Du hast eine gute Lösung, ein spannendes Projekt oder möchtest Fehler korrigieren? 

### So kannst du beitragen:

1. **Repository forken:** Klicke oben rechts auf den **Fork**-Button, um eine eigene Kopie in deinem GitHub-Account zu erstellen.
2. **Branch erstellen:** Erstelle einen Feature-Branch für deine Änderungen (`git checkout -b feature/neues-thema`).
3. **Code hinzufügen/bearbeiten:** Achte darauf, deinen Code sauber zu strukturieren und kurz zu kommentieren.
4. **Changes committen:** Beschreibe deine Änderungen verständlich (`git commit -m 'Hinzufügen: Beispiele für Raytracing-Reflexion'`).
5. **Push & Pull Request:** Pushe deine Änderungen auf deinen Fork (`git push origin feature/neues-thema`) und erstelle einen **Pull Request** an dieses Repository.
